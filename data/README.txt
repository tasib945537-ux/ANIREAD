AniRead Dub Data Directory
===========================
This directory contains verified anime dub datasets, templates, and cache files for multi-language tracking.

Files:
- dub_records_template.csv : Standard CSV template for batch importing or auditing season-specific dub records.
- dub_records.json         : Hierarchical JSON export generated by anime_dub_collector.py.

Verification Standard:
Each record requires verifiable evidence (platform, region, episode coverage, source URL, and last checked date).
No record may be marked 'CONFIRMED' without verifiable streaming proof.
